# EXP-007 — Re-identifiable Construction Outcome

**Brick / context:** `B-001`  
**Status:** Provisional

## 1. Intention / Goal

Test whether a rule-governed construction outcome can serve as a re-identifiable entity using its constructional specification, without introducing a separate primitive equality relation.

## 2. Experiment

Treat the construction specification as determining an admissible role for its outcome. A later occurrence can be recognized as corresponding to that role when it satisfies the same constructional requirements. Avoid asserting in advance that two outputs are equal as mathematical objects.

## 3. Result

The experiment clarifies a possible distinction between:

```text
object identity
```

and

```text
identity of constructional role
```

The latter can be described without immediately postulating an intrinsic object identity. However, the phrase “same constructional requirements” still requires a stable specification that can itself be re-identified. Thus the dependency has not disappeared; it has moved to the specification/rule.

More importantly, the experiment shows that a **role** can be stable before an independently characterized object is available. This is compatible with the current pre-numerical goal, but it does not yet establish that a role is an object, nor that it supplies the full notion of equality needed later.

## 4. Decision

Accept **constructional role** as a candidate intermediate structure. Do not identify it with an object or equality. The next experiment should test whether two distinguishable constructional roles can be related without already assuming numerical multiplicity or a completed collection of entities.

## 5. Epistemic Status

`Provisional`

## 6. Next Cycle

Investigate whether a constructional role can be distinguished from another role, and whether this yields the first genuinely pre-numerical multiplicity without presupposing “two”.
