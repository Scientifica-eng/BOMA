# EXP-009 — Minimal Coexistence

**Brick / context:** `B-001`  
**Status:** Provisional

## 1. Intention / Goal

Test whether distinguishable constructional alternatives can coexist within one constructional context without importing set membership or cardinal number.

## 2. Experiment

Start with a constructional context and two admissible roles only as distinct specifications, not as members of a pre-existing collection. Ask whether the context can support both alternatives as available constructions while preserving their distinguishability.

The key restriction is that we must not say “there are two objects”. The intended primitive content is only that the context admits more than one distinguishable constructional possibility.

## 3. Result

The formulation can express a weak notion of coexistence of alternatives, but only by introducing an implicit branching structure: from the same context, distinct admissible construction paths are available.

This yields an important pre-numerical structure:

```text
one context
   ├── construction path A
   └── construction path B
```

No cardinal number is needed to describe the branching itself. However, saying that both paths are “available in the same context” introduces a notion of plurality of possibilities. This plurality is structural/branching, not yet cardinal.

A second issue appears: if the two paths eventually produce distinguishable outcomes, we still need a criterion for preserving their distinction. If the paths are distinguished solely by their construction rules, the distinction is stable at the rule level; if outcomes are compared independently, equality/identity reappears.

## 4. Decision

Accept **branching/coexistence of distinguishable constructional alternatives** as the strongest candidate obtained so far for a pre-numerical multiplicity structure. Do not call it “two”, a pair, a set, or a cardinality.

The construction now suggests that multiplicity may arise first as **structural branching**, with numerical counting appearing only later as an operation performed on stable distinguishable outcomes.

## 5. Epistemic Status

`Provisional`

## 6. Next Cycle

Test whether one branch can be selected and then reproduced/iterated within the same constructional framework, and whether this introduces an elementary notion of succession without presupposing natural numbers.
