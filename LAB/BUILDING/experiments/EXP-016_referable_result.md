# EXP-016 — First Referable Result

**Starting point:** `S-001`  
**Current Brick:** `B-001`  
**Status:** Provisional

## 1. Intention / Goal

Test the weakest way in which the distinction-making act `δ` can yield something that can be referred to within the construction, without silently introducing a pre-existing object, equality, number, or set.

## 2. Experiment

We deliberately make one additional constructional choice: treat the outcome of applying `δ` as a **constructional result** `r` that can be referred to in subsequent construction.

This is not claimed to be discovered from `S-001` or forced by `B-001`. It is a new hypothesis to test.

We therefore move from:

```text
δ = distinction-making act
```

to:

```text
δ  ↦  r
```

where `r` is not yet declared to be an object in the ontological sense. It is only a named output-role of the construction.

## 3. Result

The construction becomes referentially usable: later construction can say “the result produced by `δ`” without introducing a second entity or a primitive equality relation.

However, the experiment exposes a genuine new commitment. By allowing `r` to be referred to, we have introduced a **result-role**. This is weaker than introducing an independently existing object, but it is stronger than merely having a distinction-making act.

Nothing yet licenses the inference that `r` is unique, that it persists unchanged, that another construction can reproduce it, or that there is more than one such result.

## 4. Decision

Accept `r` as the second provisional constructional Brick, with the deliberately weak interpretation **referable constructional result**.

Do not identify `r` with an object of a pre-existing domain. Do not introduce equality, multiplicity, or set membership.

This is an explicit constructional choice. If later experiments show that the role is unnecessary, incoherent, or too strong, B-002 must be revised or abandoned.

## 5. Epistemic Status

`Provisional` — chosen extension of the construction, not a derived theorem.

## 6. Next Cycle

Test whether the referable result `r` can be used as input to another construction without adding an unannounced identity or object-hood assumption.
