# REVERSE-034 — Algebraic Candidate Test

**Status:** Completed — provisional result  
**Plan stage:** Reverse engineering → structural candidate testing → pre-formal algebraic structure  
**Purpose:** Test whether construction histories satisfy the behavioral conditions needed for an additive monoidal structure, without importing a named mathematical theory into the construction.

## 1. Scope

The experiment does **not** assume that the construction has already produced a monoid, free monoid, natural numbers, or addition.

The question is narrower:

> What behavioral properties follow from composing construction histories, and which properties require explicit choices?

## 2. Candidate objects

A construction history is treated operationally as an admissible sequence of extensions.

We distinguish:

- a non-empty history that performs one or more extensions;
- a zero-step history, if the protocol elects to recognize such a history;
- composition of histories by continuing one history after another.

The zero-step history is therefore recorded as a **candidate**, not smuggled in as an already-existing mathematical identity element.

## 3. Composition test

Given histories A and B:

```text
A : start → ... → state A
B : start → ... → state B

A then B:
start → ... → state A → ... → state A+B
```

The construction-level operation is sequential composition: execute A, then continue according to B's extension pattern.

## 4. Associativity test

Compare:

```text
(A then B) then C
```

with:

```text
A then (B then C)
```

At the operational level, both describe the same ordered succession of extension events, provided composition means literal concatenation/continuation of histories.

**Result:** associativity is supported as a structural property of history composition, not introduced as an arithmetic axiom.

## 5. Identity-candidate test

A candidate zero-step history ε performs no extension.

Operationally:

```text
ε then A = A
A then ε = A
```

provided ε is admitted as a legitimate history by the construction protocol.

**Result:** an identity-like role can be expressed operationally, but the admission of ε is itself an explicit modeling choice. It must not be presented as automatically derived from earlier bricks.

## 6. Generation test

Any finite non-empty history can be decomposed into a sequence of elementary extension events.

Thus the compositional behavior is generated by repeatedly applying one elementary transition role.

**Result:** the history structure has a strong candidate for a single-generator description.

However, the phrase **single generator** remains an interpretation until the following are established independently:

1. elementary extensions are interchangeable at the required structural level;
2. no additional primitive generator is needed to describe the admissible histories;
3. the representation is independent of implementation details.

## 7. What has actually been established

At the pre-formal behavioral level we now have a candidate structure with:

```text
history composition
        +
associative sequencing
        +
possible zero-step identity
        +
finite histories generated by repeated elementary extension
```

This is strongly suggestive of a familiar algebraic structure, but the project deliberately does **not** name that structure as a construction result.

## 8. External interpretation boundary

Only after this behavioral description is complete may an external mathematical interpretation be requested.

A later comparison may ask whether the resulting behavior matches:

- a monoidal structure;
- a monoid;
- a free monoid on one generator;
- another equivalent formalization.

Such names are **interpretations**, not premises.

## 9. Critical finding

The algebraic-looking properties are not all equally primitive:

```text
associative composition  ← strongly induced by sequential history concatenation
identity element         ← requires explicit admission of zero-step history
single-generator reading ← plausible, but still an interpretation
formal algebraic carrier ← not yet selected
```

Therefore REVERSE-034 does **not** justify the statement "we have already built a free monoid".

It justifies the weaker and more precise statement:

> The construction-history layer exhibits behavior compatible with an associative composition law and, conditional on admitting the zero-step history, an identity-like role; finite histories are generated through repeated application of the elementary extension operation.

## 10. Plan position

The reverse path has now completed the **candidate-structure testing** stage.

We remain **before formal mathematical identification** and before any commitment to a particular foundational framework.

The next stage is to test whether the candidate structure itself suffices to produce a stable notion of quantity/depth and whether that notion can support an external identification with natural-number structure without becoming a hidden premise.
