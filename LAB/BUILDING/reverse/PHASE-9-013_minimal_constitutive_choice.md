# PHASE-9-013 — Minimal Constitutive Choice

## Status

Phase 9 — formal matching against the natural-number target.

## Purpose

Identify the smallest explicit constitutive choice that remains after the framework-neutral finite generative construction, the four formal interpretations, and the attempted neutral completion principles.

## Starting point

The project has established a robust finite generative core and a behavioral target approximating a successor-chain. PHASE-9-011 and PHASE-9-012 showed that both global completion and universal characterization remain external burdens once they are made mathematically precise.

The present test therefore asks a different question:

> What is the smallest thing we must explicitly choose, rather than pretend to derive, in order to continue to a complete mathematical natural-number object?

## Candidate constitutive choices

Several candidates were considered:

1. **Choose a formal domain** containing exactly the intended stages.
2. **Choose a closure/completion principle** asserting the intended global totality.
3. **Choose a universal-property framework** in which the intended object is canonical.
4. **Choose a particular mathematical framework** such as Peano, free monoid, initial algebra, or NNO.

These are not equivalent in strength or semantic scope, but they are different ways of packaging the remaining formal commitment.

## Result

The strongest current reduction is:

> The irreducible constitutive step is not the naming of \(\\mathbb N\) itself. It is the explicit adoption of a formal regime in which the intended successor-chain is admitted as a complete mathematical object with a criterion of identity and a rule governing the scope of admissible stages.

A minimal practical version is therefore:

```text
CONSTITUTIVE CHOICE
===================
Declare a formal realization regime R such that:

(a) the observed initial/extension behavior is represented;
(b) admissible stages are governed by the declared completion rule;
(c) identity/equivalence of realizations is explicitly fixed;
(d) the regime supplies the formal resources needed for canonical interpretation.
```

This is intentionally more abstract than choosing Peano or NNO. It does not claim that such a regime has been uniquely derived. It says only that some regime of this kind must be chosen if the project is to cross from the pre-formal behavioral target to a complete mathematical object.

## What this choice does NOT assume

The constitutive choice does not require us, at this stage, to assert:

- that Peano axioms are uniquely fundamental;
- that set theory is the correct ontology;
- that category theory is ontologically prior;
- that free-monoid or initial-algebra language is primitive;
- that the pre-formal layer already contains formal equality or totality.

Those are framework-specific refinements that can be added after the constitutive boundary is declared.

## Why this is the current minimum

If no formal regime is chosen, the project can continue to describe finite constructional behavior and its successor-chain target, but it cannot honestly claim to have a complete mathematical object with globally fixed identity and scope.

If a formal regime is chosen, the remaining question becomes comparative rather than foundationally opaque:

```text
pre-formal core
    ↓
constitutive formalization choice
    ↓
explicit framework realization
    ↓
canonical completed object
```

Thus the project can now distinguish a **constitutive choice** from a **derived consequence**.

## Important boundary finding

This does not establish that the constitutive choice is philosophically arbitrary. It establishes only that it is not currently derivable from the project's framework-neutral constructional core.

The correct methodological posture is therefore:

> Declare the constitutive choice openly, measure its added commitments, and test whether the final mathematical object depends materially on which realization regime is chosen.

## Consequence for the project

Phase 9 has now reached a point where continuing to search for a completely framework-free completion theorem is unlikely to be productive without first deciding whether the project accepts an explicit constitutive boundary.

The next task should therefore be comparative: choose one minimally specified realization regime for continuation, then verify that the resulting natural-number structure satisfies the target properties, while keeping the constitutive boundary permanently visible.

## Current conclusion

The smallest explicit commitment currently identified is:

> **Choose a formal realization regime that fixes the admissible domain, identity/equivalence, and completion rule for the successor-chain.**

Everything more specific—Peano, free monoid, initial algebra, NNO—belongs to the subsequent framework-level realization choice.

## Rule for Phase 9

The constitutive formalization boundary must never be presented retrospectively as a theorem derived from the pre-formal core.

## Plan position

Substage 013 — Minimal constitutive choice identified.
