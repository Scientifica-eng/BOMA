# PHASE-9-001 — Peano-Style Formal Matching

## Status

Phase 9 — Formal matching against the natural-number target.

## Purpose

Test the construction under an explicitly declared Peano-style formalization. This is a conditional interpretation, not a claim that Peano arithmetic is the project's native or uniquely justified foundation.

## Input from the neutral construction

The preceding phases supply:
- a distinguished initial structural role;
- an elementary extension/transition role;
- finite histories generated by repeated extension;
- construction depth;
- finite decomposition by reversing elementary extensions;
- sequential composition of histories;
- operational associativity of composition;
- local referenceability without a prior global domain.

## Formalization choice for this test

For this test only, introduce a formal carrier N, a distinguished initial element 0, and a unary successor operation S. Also assume an explicit closure/induction principle sufficient to identify the intended generated domain.

These are new formal commitments for the test.

## Matching map

```text
constructional initial role  <->  0
one elementary extension    <->  S
finite extension history   <->  finite iteration of S from 0
construction depth          <->  stage index in the formal model
history composition         <->  composition of successor stages
```

## Conditional result

Under the declared Peano-style formalization, the finite construction histories map coherently to natural-number terms generated from 0 by S. The decomposition result corresponds to finite predecessor decomposition. The closure/induction commitment is what upgrades the finite generated behavior to the intended total natural-number domain.

## What is not proved

This test does not prove that:

1. the Peano-style framework is forced by the pre-formal construction;
2. the induction principle is derived from the neutral layer;
3. the resulting formal object is uniquely selected before framework choice;
4. the project has a framework-independent derivation of N.

## Boundary finding

```text
neutral construction
        |
        v
initial role + elementary extension + finite generation
        |
        v
explicit Peano formalization
        |
        v
formal domain + successor + closure/induction
        |
        v
Peano-style natural-number structure
```

The decisive imported ingredient is the global closure/induction principle. It is not part of the local construction itself.

## Rule for Phase 9

Every theorem obtained through a framework-specific axiom must remain explicitly conditional on that framework. No framework-specific result is retroactively promoted to a pre-formal fact.
