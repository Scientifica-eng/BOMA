# REVERSE-020 — Internal Completeness of the Pattern Chain

**Status:** Experiment completed — provisional result  
**Path:** `LAB/BUILDING/reverse`  
**Predecessor:** `REVERSE-019`

## 1. Intention / Goal

Test whether the construction protocol itself can determine the complete horizon of the unlabeled pattern chain, without importing a ready-made completeness, set, cardinality, or induction theory.

## 2. Experiment

We compare three readings of the pattern chain:

```text
A — operational horizon
    the patterns actually generated by carrying out the protocol

B — potential horizon
    patterns that could be generated by allowed continuation of the protocol

C — completed mathematical domain
    a formally constituted domain containing exactly the intended patterns
```

The test asks whether A or B can be promoted to C using only the local construction rules.

## 3. Result

### A — Operational horizon

This is internally definable: a pattern belongs to the current construction horizon when it has actually been produced by the protocol.

No numerical counting, set membership, or external completeness principle is required for this notion.

### B — Potential horizon

This can also be described operationally: a pattern is reachable by a permitted continuation of the protocol.

However, this is a counterfactual/possibility notion. It does not by itself produce a simultaneously constituted domain of all such patterns.

### C — Completed mathematical domain

The local transition protocol does **not** by itself establish that A or B is a completed domain. To assert that all and only the intended patterns constitute a mathematical domain requires an additional constitutive commitment.

This commitment may be expressed in different theoretical languages, but the present project remains neutral and does not select one yet.

## 4. Critical Finding

The phrase "complete chain" is therefore not derivable from the local protocol alone.

What is derivable internally is:

```text
actual generation
      ↓
operational horizon
```

and:

```text
allowed continuation
      ↓
potential horizon
```

The transition from either horizon to a completed domain is an additional step.

## 5. Consequence for the Natural-Number Reverse Path

The reverse path has now isolated a likely constitutive boundary:

```text
pre-mathematical construction
        ↓
actual/potential generated horizon
════════════════════════════════
additional constitutive commitment
════════════════════════════════
        ↓
completed abstract domain
```

This does not identify the commitment uniquely. It only establishes that one is needed if the project wants a completed domain rather than an ongoing construction process.

## 6. Decision

1. Do not import a completeness principle yet.
2. Treat the operational and potential horizons as legitimate pre-formal notions.
3. Mark the completed-domain transition as an explicit candidate choice point.
4. Preserve theoretical neutrality: no set-theoretic, type-theoretic, category-theoretic, or other formalization is selected at this stage.

## 7. Next Question

The next experiment should ask whether the additional constitutive commitment can itself be stated in a theory-neutral operational form, such as a rule for **closure of admissible patterns**, or whether any such rule inevitably becomes a mathematical foundation choice.
