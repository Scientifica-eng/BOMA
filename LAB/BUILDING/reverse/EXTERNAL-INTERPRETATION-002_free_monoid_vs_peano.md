# EXTERNAL-INTERPRETATION-002 — Free Monoid vs Peano

## Purpose

Compare two external mathematical readings of the neutral pre-formal structure without selecting either as the project's native foundation.

## Candidate A — Free monoid on one generator

The constructional evidence supports:
- a repeatable elementary extension role;
- compositional histories;
- associative sequential composition;
- a candidate empty history as identity;
- finite decomposability into elementary extensions.

A free monoid interpretation would additionally formalize these ingredients as a domain with an associative binary operation and an identity, generated by one basic step, together with the relevant universal property.

The universal/free claim is an external mathematical characterization, not a result already established by the pre-formal experiments.

## Candidate B — Peano-style successor structure

The constructional evidence also supports:
- an initial carrier;
- a successor-like extension operation;
- finite chains generated from the initial carrier.

A Peano interpretation would additionally require a formal domain and an induction/closure principle sufficient to identify the intended totality.

## Comparison

| Feature | Free-monoid reading | Peano-style reading |
|---|---|---|
| Initial role | identity/empty-history candidate | distinguished initial element |
| Basic step | generator / elementary extension | successor-like operation |
| Composition | central | secondary or derived |
| Associativity | explicit algebraic axiom/property | not the defining feature |
| Identity | explicit | not usually the central primitive |
| Totality | requires a formal domain | requires formal domain + induction/closure |
| Universal property | central to “free” | not central |
| Fit to current construction | strong | strong |
| Added commitments | algebraic identity/composition/free property | formal totality + induction-style principle |

## Decision

Neither candidate is declared the project's foundation.

The evidence currently supports a **pre-formal structure compatible with both readings**. The difference lies mainly in what each framework adds at formalization time.

The next test is therefore not to choose a winner, but to isolate the **minimal invariant specification** shared by both readings and determine which formal commitments are genuinely necessary for the target result.
