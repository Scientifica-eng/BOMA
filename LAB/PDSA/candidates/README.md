# Future Experiment Candidate Index

This directory contains research candidates discovered during active work and preserved for later execution.

A candidate record is **not** execution authorization and is **not** a Frozen Plan. Before implementation, a future agent must reverify GitHub current state, obtain any required owner authorization, and create a separately frozen PDSA Plan.

Governance protocol:

`LAB/PDSA/FUTURE_EXPERIMENT_CANDIDATE_PROTOCOL_001.md`
