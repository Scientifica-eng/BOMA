## Purpose

Define the acceptance conditions a future formal realization must satisfy before BOMA may classify it as a natural-number core.

This cycle defines the target only. It does not construct `TCT-BLOCK-006`.

## Inputs

- calibrated pre-numerical TCT path through `TCT-BLOCK-005`;
- `PDSA-TCT-008` calibration result;
- historical framework-comparison and formalization-boundary learning.

## PLAN

Separate:

```text
N-CORE
formal carrier, identity, initial role, successor, generatedness,
induction/recursion adequacy, TCT realization, identification evidence

N-ARITHMETIC PACKAGE
addition, multiplication, order, and later arithmetic structure
```

The specification must not select a realization framework silently.

Candidate realization styles may formulate the required properties differently; those differences must remain explicit.
